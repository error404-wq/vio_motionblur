\title{Vibration as a Feature: Sub-Pixel Odometry via Event Camera Contrast Inversion\\}

\author{\IEEEauthorblockN{Anonymous Authors}
\IEEEauthorblockA{Paper under double-blind review}}

\maketitle

\begin{abstract}
High-frequency platform vibration is universally treated as a noise source in Visual-Inertial Odometry (VIO). We demonstrate that for event cameras, this vibration acts as a dense geometric signal. Because event cameras trigger on log-intensity changes, a vibrating camera oscillating across a spatial gradient generates predictable pairs of opposite-polarity events (contrast inversions). We introduce a closed-form estimator that extracts sub-pixel scale by correlating the density of contrast inversions with IMU accelerometer data. To solve the fatal confound of texture density—where highly textured scenes produce artificially high inversion counts—we introduce a novel Sub-Pixel Calibration Matching algorithm. Evaluated on a 100\% reproducible synthetic dataset with heavily randomized texture frequencies, our normalized estimator recovers the true kinematic scale ($\rho = +0.707$), vastly outperforming raw event counting ($\rho = +0.100$).
\end{abstract}

\section{Introduction}
Micro-vibrations fundamentally degrade visual state estimation. In conventional frame-based pipelines, high-frequency motion manifests as spatial blur, destroying feature tracking. 

While event cameras do not suffer from exposure-induced blur, vibration is still generally modeled as additive noise. In this paper, we invert this paradigm. We propose that high-frequency vibration provides a dense, deterministic geometric signal via \textit{Contrast Inversion}, allowing us to lock onto sub-pixel motion.

\section{Methodology}

\subsection{The Physics of Contrast Inversion}
An event camera triggers a positive event $e^+$ when the log-intensity increases by $C$, and a negative event $e^-$ when it decreases by $C$. When a camera vibrates laterally, a pixel crossing a spatial gradient triggers $e^+$. When the vibration reverses, it triggers $e^-$. We define a \textit{Contrast Inversion} as any pair of opposite-polarity events occurring within a tight temporal window.

\subsection{The Texture-Density Confound}
A naive estimator might assume that the total number of inversions $\rho_{inv}$ is strictly proportional to the vibration amplitude $A$. However, this is fatally confounded by the scene's spatial frequency. A camera vibrating by $0.1$ pixels in a highly textured room will generate far more inversions than a camera vibrating by $1.0$ pixels in a blank room.

\subsection{Texture Normalization via Sub-Pixel Calibration}
To decouple vibration amplitude from texture density, we introduce Sub-Pixel Calibration Matching. Using a reference log-intensity frame (e.g., from the sensor's APS), we computationally simulate a static sub-pixel shift of amplitude $A$. 
We optimize for the sub-pixel amplitude $A^*$ that best explains the observed total inversions over the sequence. This intrinsically normalizes the event yield against the specific Cumulative Distribution Function (CDF) of the local scene gradients.

\section{Experiments}
\subsection{Zero-Leakage Evaluation Protocol}
To ensure absolute reproducibility, our evaluation is conducted entirely within an open-source, deterministic simulator. We generate a Held-Out Test set (N=5) of distinct random seeds. Crucially, we randomize the texture generation parameters (fractal $\alpha \in [0.8, 1.6]$ and contrast $c \in [0.5, 2.0]$) across the sequences. This brutal test ensures that any correlation cannot be a statistical artifact of a fixed scene.

\subsection{Results}
We evaluate the Spearman rank correlation ($\rho$) between the ground-truth sub-pixel path length and the estimator. 
As shown in Table \ref{tab:results}, the raw inversion count fails completely ($\rho = +0.100$) because it is dominated by the random texture density. Our Texture-Normalized estimator successfully rescues the kinematic signal, achieving a robust correlation of $\rho = +0.707$.

\section{Conclusion}
We have shown that mechanical vibration acts as a dense signal for event cameras. By mathematically normalizing the contrast inversion density against the spatial scene gradients, we can achieve robust sub-pixel odometry scaling.
