# vio_motionblur Repository

This repository contains the research code and manuscript for the project **"Motion Blur as a Feature for Event‑Based Depth Estimation"**.

## Contents

- `paper_draft.tex` – Full LaTeX source of the 2‑page conference paper.
- `scripts/` – Python scripts used for the peer‑review pipeline and data‑leakage checks.
- `README.md` – This file.
- `.gitignore` – Ignores LaTeX auxiliary files and compiled PDFs.

## Building the Paper

If you have a LaTeX distribution installed (e.g., TeX Live or MikTeX), you can compile the manuscript locally:

```bash
pdflatex paper_draft.tex
```

The generated `paper_draft.pdf` can be opened with any PDF viewer.
